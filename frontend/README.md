# frontend/ — SurfPOS AI Flutter App

Mobile-first Flutter client (Android/iOS, Flutter Web/desktop runners scaffolded for future use). See [docs/02_ARCHITECTURE.md § 2](../docs/02_ARCHITECTURE.md#2-frontend-flutter) for the architectural role of this app, and [docs/06_UI_UX_GUIDE.md](../docs/06_UI_UX_GUIDE.md) for the design system it must follow.

**Status:** design system + reusable widget library complete; Splash is the first of 26 planned screens implemented (see [docs/13_CLAUDE_CONTEXT.md](../docs/13_CLAUDE_CONTEXT.md) and `.claude/projectStatus.md`). `web/` is scaffolded for local dev/testing; `android/`, `ios/`, `linux/`, `macos/`, `windows/` remain placeholders until each platform is actually targeted.

## Structure

| Folder | Purpose |
|---|---|
| `android/`, `ios/`, `linux/`, `macos/`, `windows/`, `web/` | Platform runners — generated by `flutter create`, not hand-written (`web/` scaffolded; others still placeholders) |
| `assets/` | Images, icons, animations, fonts, logos (Surfboard Payments mark bundled here), sounds |
| `lib/app/themes/` | The design system: colors, typography, spacing/radius/motion, shadows, `ThemeData` |
| `lib/app/` | App-shell bootstrap: routing, theming, constants, build configs, localization |
| `lib/core/widgets/` | The reusable widget library: buttons, cards, text fields, dialogs, bottom sheets, loading/skeletons, empty/error states, app bars, navigation, branding |
| `lib/features/` | One folder per business capability — see [lib/features/README.md](lib/features/README.md) |
| `lib/main.dart` | Entry point (wires `SurfPosApp`) |
| `test/`, `integration_test/` | Automated tests |
| `pubspec.yaml` | Package manifest — `google_fonts`, `flutter_svg`, `lucide_icons` |
