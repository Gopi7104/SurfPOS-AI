# macos/ (Flutter Platform Runner)

This folder is reserved for the **macos** platform runner project generated by Flutter tooling.

It is intentionally empty in this documentation-only scaffold. Once implementation begins (see [10_TASKS.md](../../docs/10_TASKS.md) Phase 0), run:

```bash
flutter create --platforms=macos .
```

from the `frontend/` directory to populate this folder with the standard Flutter-generated platform project. Do not hand-write files here before that step.
