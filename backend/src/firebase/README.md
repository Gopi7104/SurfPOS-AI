# firebase/

Firebase Admin SDK initialization (`firebase.js`) and thin RTDB/Storage access helpers used by `modules/*` services. This is the only place the Admin SDK is initialized — see [docs/02_ARCHITECTURE.md § 4](../../../docs/02_ARCHITECTURE.md#4-firebase-platform-layer) and [docs/07_CODING_RULES.md § 16](../../../docs/07_CODING_RULES.md#16-firebase-best-practices).
